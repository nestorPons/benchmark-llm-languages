# T5 — Web: SSR o SPA con formulario y llamada a la API

Implementa en **{language}** (runtime: `{runtime}`) una pequeña aplicación web que:

- Muestre un formulario (por ejemplo, alta de un `item`).
- Al enviarlo, llame a una API (`POST /items`) y muestre el resultado.
- Liste los elementos existentes (`GET /items`).
- Sirva una página inicial en `/`.

Puede ser SSR o SPA, pero debe quedar autocontenida y ejecutable en el puerto
8005. Incluye `README.md` con instrucciones. Escribe cada fichero en un bloque de
código con su ruta.

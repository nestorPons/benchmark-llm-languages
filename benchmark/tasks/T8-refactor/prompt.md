# T8 — Refactor con tests existentes

Se te da un repositorio en **{language}** (cuyo contenido se incluye a
continuación) con tests ya presentes.
Refactoriza el código para mejorar la modularidad sin cambiar el comportamiento:

- Extrae la lógica de validación a un módulo reutilizable.
- Elimina duplicación de código.
- Mantiene la misma API externa y los tests deben seguir pasando.

Escribe cada fichero modificado en un bloque de código con su ruta. No añadas
comportamiento nuevo.

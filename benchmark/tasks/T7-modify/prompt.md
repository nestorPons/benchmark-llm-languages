# T7 — Modificar un proyecto existente

Se te da un repositorio base en **{language}** con **{framework}**, cuyo contenido
completo se incluye a continuación. Realiza dos cambios:

1. Añade la funcionalidad `POST /items/batch` (crear varios `item` en una petición).
2. Corrige el bug existente en la validación de `price` (acepta valores negativos;
   debe rechazarlos con 400).

No reescribas el proyecto: modifica solo los ficheros necesarios. Escribe cada
fichero modificado en un bloque de código con su ruta (incluye el fichero
completo). Mantén el estilo existente.
